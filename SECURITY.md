# Security policy

Please report suspected vulnerabilities privately to the repository owner
instead of opening a public issue. Include affected versions, reproduction
steps, impact, and any suggested mitigation. Do not include real WhatsApp
session material, QR codes, pairing codes, credentials, message content, or
database dumps.

Security fixes will be released as soon as they have been validated against a
real MariaDB integration environment. Consumers should pin an explicit
`mdbstore` version and review Hypermeow dependency updates before deploying.
